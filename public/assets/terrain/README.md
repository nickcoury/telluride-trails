# Terrain Detail PBR Assets

All textures in this directory are CC0 (Public Domain) from [Poly Haven](https://polyhaven.com/textures), resized to 512x512 WebP with normal XY + roughness packed into `*_nrm_rough.webp` (`R=normal.x`, `G=normal.y`, `B=roughness`):

- `rock_*`: `cliff_side` (CC0, Poly Haven)
- `talus_*`: `gray_rocks` (CC0, Poly Haven)
- `dirt_*`: `stony_dirt_path` (CC0, Poly Haven)
- `grass_*`: `sparse_grass` (CC0, Poly Haven)
- `forest_*`: `forest_ground_04` (CC0, Poly Haven)
- `snow_*`: `snow_02` (CC0, Poly Haven)
