# Orthoimagery Tiles (`public/data/imagery`)

Color-balanced, de-hazed Web Mercator (`EPSG:3857`) aerial imagery tiles for Telluride + the San Juan Mountains.

## File Layout & Format
- Path: `{z}/{x}/{y}.webp`
- Image format: **WebP** (`256x256`, `padding = 0`, sRGB, quality `81`).
- Processing: Consistent global atmospheric haze-floor removal, white-point normalization, shadow-preserving gamma lift, and subtle midtone vibrancy boost (identical pixel-wise LUT across all tiles so adjacent tiles have zero seams).

## Zoom Coverage
- `z8`–`z10`: Extended ~110 km non-playable far-horizon ring (`horizon.bounds`: `W -109.05, S 36.95, E -106.55, N 38.90`, `playable: false`).
- `z11`–`z14`: Full playable bounding box (`W -108.02, S 37.68, E -107.25, N 38.10`).
- `z15`–`z16`: Trail, road, race, and town corridor (`manifest.json`).
- `z17`: Telluride town, Mountain Village / Gondola, and Bridal Veil corridor (`manifest.json`).

## 2D Map Overview (`overview.webp` + `overview.json`)
- `overview.webp`: `2048x1415` shaded-relief + color-balanced orthoimagery composite covering the exact playable `bounds`.
- `overview.json`: `{ image, width, height, bounds, worldBounds: { minX, maxX, minZ, maxZ }, attribution }` mapped linearly to `src/core/geo.js` scaled Web Mercator world meters.

## `manifest.json` Schema
- `version`: `1`
- `format`: `"webp"`, `ext`: `"webp"`, `tileSize`: `256`, `padding`: `0`, `encoding`: `"srgb"`
- `bounds`, `origin`, `minZoom`, `maxZoom`, `tileCount`, `totalBytes`, `attribution`, `quality`, `colorBalanced`
- `tiles`: keyed by zoom string, using either `{ full: true, count, xMin, xMax, yMin, yMax }` or `{ full: false, count, xMin, xMax, yMin, yMax, rows }` with inclusive `[xStart, xEnd]` span pairs per `y` row.
