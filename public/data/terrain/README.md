# Terrain Elevation Tiles (`public/data/terrain`)

Web Mercator (`EPSG:3857`) elevation tiles for the Telluride + San Juan Mountains playable bounding box.

## Bounds & Origin
- Bounding box (WGS84): `west = -108.02`, `south = 37.68`, `east = -107.25`, `north = 38.10`
- World origin (Telluride): `lat0 = 37.9375`, `lon0 = -107.8123`

## File Layout & Format
- Path: `{z}/{x}/{y}.webp`
- Image format: **lossless WebP** (`256x256`, `padding = 0`), pixel-for-pixel identical to source Terrarium PNGs.
- Encoding: **Mapzen / AWS Terrarium RGB**:
  ```js
  elevationMeters = R * 256 + G + B / 256 - 32768
  ```
  Decode in browser with `createImageBitmap(blob, { colorSpaceConversion: 'none', premultiplyAlpha: 'none' })`.

## Zoom Coverage
- `z8`–`z10`: Extended ~110 km non-playable far-horizon ring (`horizon.bounds`: `W -109.05, S 36.95, E -106.55, N 38.90`, `playable: false`) covering Uncompahgre/Wetterhorn, La Platas, Dolores valley, and Grand Mesa direction.
- `z11`–`z14`: Full playable bounding box.
- `z15`: Core trail, road, race, and town corridor (see `manifest.json`).

## `manifest.json` Schema
- `version`: `1`
- `format`: `"webp-lossless"`, `ext`: `"webp"`, `tileSize`: `256`, `padding`: `0`
- `encoding`: `"terrarium"`, `encodingFormula`: `"elevationMeters = R * 256 + G + B / 256 - 32768"`
- `bounds`: `{ west, south, east, north }`
- `origin`: `{ lat, lon }`
- `minZoom`, `maxZoom`, `tileCount`, `totalBytes`, `attribution`
- `tiles`: object keyed by zoom string (`"8"`, `"9"`, ...):
  - `{ full: true, count, xMin, xMax, yMin, yMax }` when every tile in `[xMin..xMax] x [yMin..yMax]` exists.
  - `{ full: false, count, xMin, xMax, yMin, yMax, rows }` where `rows[String(y)]` is a flat array of inclusive `[xStart, xEnd]` span pairs `[x0, x1, x2, x3, ...]`.
