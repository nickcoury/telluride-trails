# Land Cover Mask Tiles (`public/data/cover`)

Web Mercator (`EPSG:3857`) RGBA surface/vegetation masks for Telluride + the San Juan Mountains, used for procedural tree/rock/grass/water placement and terrain detail-texture splatting.

## File Layout & Format
- Path: `{z}/{x}/{y}.png`
- Image format: **PNG RGBA** (`256x256`, `padding = 0`).
- Channel semantics (each `0..255` representing `0.0..1.0` density/weight):
  - `R`: Forest density (conifer + aspen/deciduous + riparian woody canopy; tapers smoothly across treeline `~11,300–12,150 ft` and on cliffs)
  - `G`: Bare rock / scree / talus (NLCD barren + high-alpine talus chutes + steep cliff slopes ramping to `1.0` above `45°` + imagery rock cues)
  - `B`: Open water (lakes, reservoirs, major rivers)
  - `A`: Alpine tundra / grass / meadow / subalpine shrub (including wetlands/willow meadows and above-treeline tundra)

> **Important decode note:** Because `A` stores alpine tundra/grass (not opacity), browsers/canvas MUST decode these PNGs with **no alpha premultiplication** and **no color space conversion**:
> `createImageBitmap(blob, { premultiplyAlpha: 'none', colorSpaceConversion: 'none' })`
> or raw PNG zlib inflate in a Worker. Using `<canvas>` `getImageData()` directly will premultiply RGB by A and zero out R/G/B wherever tundra (`A`) is `0`.

## Zoom Coverage
- `z13`: Full playable bounding box.
- `z14`: Trail, road, race, and town corridor (see `manifest.json`).

## `manifest.json` Schema
- `version`: `1`
- `format`: `"png-rgba"`, `ext`: `"png"`, `tileSize`: `256`, `padding`: `0`, `encoding`: `"rgba-cover"`
- `channels`: `{ R, G, B, A }` description
- `decodeNote`: premultiplied-alpha warning
- `bounds`, `origin`, `minZoom`, `maxZoom`, `tileCount`, `totalBytes`, `attribution`
- `tiles`: keyed by zoom string (`full` or `rows` inclusive `[xStart, xEnd]` span pairs).
